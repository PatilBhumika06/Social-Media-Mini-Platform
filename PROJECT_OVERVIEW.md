# Project Overview (English)

This project is a social media platform clone, inspired by popular apps like Instagram. It provides features such as:
- User registration and login
- Posting photos and videos
- Sharing stories
- Following and unfollowing users
- Sending and receiving messages
- Viewing activity feeds

The backend is built using Node.js (JavaScript), and the codebase is organized into backend and frontend folders. The backend manages user data, authentication, posts, reels, stories, and messaging. The frontend (not fully shown here) is intended to provide the user interface. The project also includes test scripts to verify different features and ensure reliability.

**Technologies Used:**
- Node.js (JavaScript) for backend logic
- (Possibly) Express.js for server routing
- File-based storage or a database (not fully shown)
- Test scripts in JavaScript and Dart
- Modular code structure for maintainability
